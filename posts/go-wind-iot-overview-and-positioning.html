GoWind IoT（风行物联网）：从设备接入到告警运维的设备管理平台

本文回答一个问题：手上有设备要联网管理——接入、监控、告警、远程升级、视频查看这一整套，一个私有化平台能覆盖到什么程度？

利益相关声明：我是 GoWind IoT 的作者。本文只讲平台做了什么、你能用它做什么，文末会如实列出它不覆盖的部分。

一、平台定位

风行物联网是一套私有化部署的物联网设备管理与分析平台，覆盖设备从「上电接入」到「退役下线」的完整生命周期：

  • 设备建模：产品 → 物模型 → 设备三级结构，属性、事件、命令统一定义；
  • 设备接入：标准 MQTT 协议接入，支持设备认证与零预置凭证的动态注册；
  • 数据与告警：遥测时序存储、实时监控、规则引擎与告警状态机；
  • 远程运维：下行命令、设备影子、OTA 升级、视频监控、运维工单。

平台按租户隔离数据，权限、审计、多语言（中/英）这些平台底座开箱即用——可以直接作为产品级平台交付给多客户使用。

二、总览驾驶舱：打开就知道全局状态

登录第一屏是总览驾驶舱：设备总数、在线/离线/未激活分布、活跃告警、7 日遥测量，配上告警趋势与状态分布图；右侧是实时事件流——遥测、告警、设备状态变化在这里实时滚动，不需要刷新页面。

三、设备接入与管理

  • 产品与物模型：先建产品、定义物模型（结构化的属性定义与存在性校验），再在产品下注册设备，凭证自动签发；
  • 动态注册：设备可以零预置凭证上电，按产品级密钥动态注册换取接入凭证——产线烧录同一套出厂固件即可，不必逐台预写密钥；
  • 生命周期：注册、激活、在线离线、禁用、删除全程可管；支持设备分组，为批量操作和 OTA 圈选提供维度。

四、遥测与实时监控

遥测数据分「最新值」和「历史时序」双轨存储：最新值供仪表与状态判断，历史数据供时间范围查询与图表分析。设备上报后，控制台通过服务端推送实时刷新，不需要轮询。

五、告警中心与规则引擎

告警不是一条日志，而是完整的状态机：触发 → 未确认 → 已确认 → 清除，每次状态迁移都留时间戳，支持确认与清除联动，恢复自动清除。

触发方式有两种：

  1. 遥测驱动：设备上报命中阈值即触发——比如温度超限告警；
  2. 定时触发：按 cron 表达式周期性评估——比如每小时巡检一次设备状态。

规则以可视化规则链编排：过滤节点 → 告警节点 → 通知、设备命令、外部系统转发三类动作自由组合；配合地理围栏（GeoJSON 多边形），设备进出围栏自动触发/清除告警——车辆、资产定位场景直接可用。

六、设备控制与视频监控

  • 下行命令：平台向设备下发命令，设备回执确认，命令全程状态可跟踪，不丢不重；
  • 设备控制台：面向设备操作的统一控制面板；
  • 视频监控：摄像头类设备接入后可直接在平台内观看实时画面。

七、OTA 升级与设备影子

OTA 升级覆盖完整闭环：升级包上传（自动校验 checksum）→ 圈选设备批量建任务 → 任务进度实时聚合 → 支持 PENDING/进行中/完成状态跟踪与取消；固件下载走临时授权链接分发，不暴露原始存储地址。

设备影子解决「设备不在线时也要改配置」：设备上报期望状态（desired），设备上线后自动比对下发差异（delta），影子不一致时记录漂移日志——远程改配置不再依赖设备在线窗口。

八、通知、站内信与运维工单

  • 多通道通知：邮件、短信、Telegram Bot、Webhook（钉钉/企业微信/飞书/自定义）真实投递，通知规则决定「什么事件通知谁」；
  • 站内信：平台内消息带分类与已读标记，与告警、工单联动；
  • 运维工单：设备维护工单管理，现场问题闭环跟踪。

九、多端覆盖：控制台 + 桌面端 + 移动端

同一套平台提供 Web 管理控制台、桌面客户端与移动 App，界面与数据实时同步——值班场景手机上直接看告警、看设备、看视频。

十、平台底座

  • 多租户隔离：业务数据按租户贯穿隔离，适合多客户交付；
  • 权限体系：角色—权限点—菜单三级结构，按钮级与路由级访问控制；
  • 六类审计：登录、API 调用、操作、数据访问、权限审计、策略评估；
  • 账号安全：登录策略、验证码、MFA 多因素认证；
  • 国际化：中/英双语。

十一、适合谁 / 不覆盖什么

适合：

  • 设备制造商：给自己出场的设备配一套远程管理平台（绑定自有品牌，数据留在自己服务器）；
  • 系统集成商：给园区、工厂、楼宇类项目交付设备监控方案；
  • 需要「设备 + 告警 + 工单 + 移动端」一体化能力的运维团队。

不覆盖 / 需要自建的部分：

  • 规则引擎当前是结构化节点编排（过滤/告警/通知/命令/转发），复杂自定义计算逻辑需要二开扩展；
  • 视频监控面向摄像头接入查看，不含录像存储策略管理；
  • 协议侧当前以 MQTT 接入为主，Modbus/OPC-UA 等工业协议需经网关转换。
